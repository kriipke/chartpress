Effortlessly scaffold umbrella Helm charts and their subcharts for your Kubernetes apps from a single config file. Chartpress streamlines CI/CD for cloud-native deployments—fast, flexible, and built for modern DevOps.

toc::[]

== Features

* Generate an umbrella Helm chart and its subcharts from a single config file
* Pick a workload type per subchart (Deployment, StatefulSet, or DaemonSet)
* Use it three ways: a CLI (`chartpress`), an HTTP API (`chartpress-server`), or the web wizard
* Ships reusable umbrella/subchart templates plus a Helm chart to self-host the service
* Written in Go and JavaScript

== Getting Started

=== Prerequisites

* link:https://golang.org/doc/install[Go] (1.18+ recommended)
* link:https://helm.sh/[Helm] (v3+)
* Docker (for containerized workflows; optional)

=== Installation

.Clone using Git
[source,sh]
----
git clone git@github.com:kriipke/chartpress.git
cd chartpress
----

.Build the binaries
[source,sh]
----
# CLI
go build -o chartpress ./cmd/chartpress
# HTTP server (optional)
go build -o chartpress-server ./cmd/server
----

.Run using Docker (optional)
[source,sh]
----
docker build -t chartpress .
docker run --rm -v $(pwd):/work chartpress [command] [options]
----

== Usage

=== Configuration

Chartpress reads a config file (default `./chartpress.yaml`) describing the
umbrella chart and its subcharts:

[source,yaml]
----
umbrellaChartName: saas-platform
subcharts:
  - name: api
    workload: deployment
  - name: cache
    workload: deployment
  - name: database
    workload: statefulset
----

`workload` must be one of `deployment`, `statefulset`, or `daemonset`.

=== Generate a Chart (CLI)

The `create` command renders the umbrella chart and subcharts into
`output/<umbrellaChartName>-<timestamp>/`:

[source,sh]
----
./chartpress create my-platform
----

Flags:

[cols="1,3"]
|===
| Flag | Description

| `-c, --config` | Path to the config file (default `./chartpress.yaml`)
| `--umbrella-template` | Path to the umbrella chart template (default `./templates/umbrella`)
| `--subchart-template` | Path to the subchart template (default `./templates/subchart`)
|===

Run `./chartpress --help` for all options.

=== Generate a Chart (HTTP server)

Start the server (listens on `$PORT`, default `8080`):

[source,sh]
----
./chartpress-server
----

POST a config as JSON to `/generate`. With `Accept: application/zip` the chart
archive is streamed back directly; otherwise a JSON body with a `downloadUrl`
(served from `/download/<file>`) is returned:

[source,sh]
----
curl -X POST http://localhost:8080/generate \
  -H "Content-Type: application/json" \
  -H "Accept: application/zip" \
  --data '{"umbrellaChartName":"saas-platform","subcharts":[{"name":"api","workload":"deployment"}]}' \
  -o chart.zip
----

== Example CI/CD Integration

For GitHub Actions:

[source,yaml]
----
- name: Build chartpress
  run: go build -o chartpress ./cmd/chartpress

- name: Generate umbrella chart
  run: ./chartpress create my-platform --config ./chartpress.yaml
----

== Architecture Overview

[plantuml]
----
@startuml
actor User
participant "chartpress CLI / web wizard" as Client
participant "chartpress(-server)" as Engine
participant "Chart templates" as Templates
participant "output/ (chart + .zip)" as Output

User -> Client : Provide config (chartpress.yaml / JSON)
Client -> Engine : create / POST /generate
Engine -> Templates : Render umbrella + subcharts
Engine -> Output : Write generated chart (and archive)
@enduml
----

== Development

* Go code in `cmd/` (entrypoints) and `internal/` (server logic)
* Chart templates in `templates/umbrella` and `templates/subchart`
* React/Vite web wizard in `web/`
* Makefile for common tasks (`make build-api`, `make build-web`, `make tests`)

=== Running Tests

The `tests` target posts a sample config to a running `chartpress-server`
(default port 8080) and saves the resulting archive:

[source,sh]
----
make tests
----
