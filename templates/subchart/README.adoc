= component

A subchart generated by https://github.com/kriipke/chartpress[chartpress],
deployed as a dependency of its umbrella chart. It can also be rendered
standalone (`helm template .`) for development.

== Configuration

All knobs live in `values.yaml`, which documents each block inline. When
installed under the umbrella chart, override any of them from the umbrella's
`values.yaml` under this chart's name:

[source,yaml]
----
component:
  image:
    tag: "1.2.3"
  service:
    port: 8080
----

Search `values.yaml` for `TODO(chartpress)` to find the values that must be
set before this chart is production-ready: image registry/name/tag, resource
sizing, probe endpoints, and (if exposed) `ingress.host`.
