# Instructions for coding agents working in this chart

This is an umbrella Helm chart generated by
[chartpress](https://github.com/kriipke/chartpress). Each application
component is a subchart under `charts/<name>/`; the umbrella wires them
together and carries shared values.

## Read these first

- **`docs/best-practices.adoc`** — the practices this chart implements (and
  deliberately doesn't). These are load-bearing: fill in their placeholders,
  enable what's scaffolded-off, never remove them. Topic deep-dives (probes,
  HPA, ingress, network policies, images) may also be present in `docs/`,
  depending on how the chart was generated.
- **`HANDOFF.md`** (chart root, if present) — the chart is not finished yet
  and that file is the task list for finishing it against the application
  code. Its absence means the chart was completed; still respect the
  best-practices doc when making further changes.

## Conventions

- `TODO(chartpress)` marks every value needing an app-specific answer:
  `grep -rn "TODO(chartpress)" .` is the authoritative to-do list.
- Values layering: a subchart's own `values.yaml` holds its defaults; the
  umbrella `values.yaml` overrides them under the subchart's name; shared
  settings live under `global:`.
- Shared template logic lives in umbrella-level named templates; subchart
  manifests are thin `include` stubs. Edit values or the shared defines —
  don't fork per-subchart template copies.
- Placeholders are replaced, never deleted; disabled practices (PDB,
  NetworkPolicy, securityContext) are enabled, never removed. Document
  genuine exceptions in the subchart's README.

## Hard constraints

- Never change `selectorLabels` — workload selectors are immutable in place
  and shared by Services, NetworkPolicies, and PDBs.
- Never set `replicas` alongside an HPA (`podCount.type` chooses one mode).
- Infrastructure (databases, caches, brokers) goes in `Chart.yaml`
  `dependencies:` as an upstream chart — never as a new subchart. Sidecars
  are containers in the owning pod — never a new subchart.
- No secrets in committed values files.

## Verify every change

From the chart root:

```bash
make template   # helm template — must render
make lint       # helm lint
make test       # render + kubeconform schema validation
```

Run these before considering any edit complete.
