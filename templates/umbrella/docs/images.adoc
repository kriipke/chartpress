= Image Specification in Workload Manifests
:toc:

toc::[]

== `values.yaml`

The image every subchart runs is assembled from three values, each with a
sensible default:

[source,yaml]
----
global:
  # registry/organization prefix shared by all subcharts
  repository: "registry.example.com/acme"

wallet:
  image:
    registry: ""       # optional per-subchart override of global.repository
    name: wallet       # defaults to the chart name
    tag: "26.6.0"      # defaults to the chart's appVersion
----

== `_helpers.tpl`

Each subchart resolves its image with the `<chart>.image` helper:

[source]
----
{{- define "chart-name.image" -}}
{{- $registry := .Values.image.registry | default .Values.global.repository -}}
{{- $name := .Values.image.name | default .Chart.Name -}}
{{- $tag := .Values.image.tag | default .Chart.AppVersion -}}
{{- if $registry }}
{{- printf "%s/%s:%s" $registry $name $tag }}
{{- else }}
{{- printf "%s:%s" $name $tag }}
{{- end }}
{{- end }}
----

Example output:

[source,yaml]
----
image: "registry.example.com/acme/wallet:26.6.0"
----

image registry:: defined once in the umbrella chart at
`.Values.global.repository`; a per-subchart override can be made at
`.Values.image.registry` in the subchart's `values.yaml`.
image name:: expected at `.Values.image.name`; in its absence `.Chart.Name`
is used.
image tag:: expected at `.Values.image.tag`; in its absence
`.Chart.AppVersion` from `Chart.yaml` is used — keep it accurate.

== Workload manifests

The shared containers helper renders the image for every workload kind:

[source,yaml]
----
containers:
  - name: {{ .Chart.Name }}
    image: {{ include (print .Chart.Name ".image") . }}
    imagePullPolicy: {{ .Values.image.pullPolicy | default "IfNotPresent" }}
----
