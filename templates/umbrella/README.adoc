= umbrella-chart

An umbrella Helm chart generated by https://github.com/kriipke/chartpress[chartpress].
Each application component lives in its own subchart under `charts/`; this
chart wires them together and carries the values shared by all of them.

== Layout

[source]
----
.
├── Chart.yaml          # umbrella metadata + subchart dependency list
├── values.yaml         # global values + per-subchart overrides
├── templates/          # shared named templates (_helpers, workloads, ...)
├── charts/<name>/      # one subchart per component (editable sources)
└── tests/              # render + kubeconform validation script
----

Values under a subchart's name in `values.yaml` override that subchart's own
`values.yaml`. Shared settings live under `global:`.

== Finishing this chart

This is a starter: the structure and best practices are in place, the
app-specific values are not. `HANDOFF.md` at the chart root is the finishing
checklist — hand it, together with the application code, to a developer or a
coding agent (`AGENTS.md`/`CLAUDE.md` orient agents automatically). Delete
`HANDOFF.md` when the chart is finished.

The quick version: search the chart for `TODO(chartpress)` markers and review
each one — image registry/tags, resource sizing, probe endpoints, ingress
hosts, and replica/autoscaling settings.

The practices this chart implements (and deliberately doesn't) are documented
in link:docs/best-practices.adoc[docs/best-practices.adoc] — they are to be
respected when finishing or extending the chart: placeholders are replaced,
never deleted; disabled practices are enabled, never removed.

== Development

Render all manifests::
+
[source,bash]
----
make template
----

Lint the chart::
+
[source,bash]
----
make lint
----

Render and validate against the Kubernetes schemas (requires `kubeconform`)::
+
[source,bash]
----
make test
----
